# Magomba Trust Microfinance

Sistem profesional kwa kumanagia na kutoa mikopo kwa magomba trust microfinance.

## Features
- ✅ Usimamizi wa magomba (groups)
- ✅ Kutoa mikopo (loan disbursement)
- ✅ Kukusanya bayuni (payment tracking)
- ✅ Upload picha (ID, muhusika, mdhamini)
- ✅ Ripoti na analytics
- ✅ Dashboard ya kila mtu

## Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js + Express
- **Database:** PostgreSQL
- **Storage:** Local/Cloud (picha)

## Quick Start

### Prerequisites
- Node.js v16+
- PostgreSQL 12+
- npm/yarn

### Installation

**Backend:**
```bash
cd backend
npm install
cp .env.example .env
# Edit .env with your database credentials
npm run dev
```

**Frontend:**
```bash
cd frontend
npm install
npm start
```
